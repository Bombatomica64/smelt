# Haiku audit: smelt repo (Phase 0-6)

Scope: every tracked file outside third_party/, examples/, blocker-logs/ (Phase 1 survey), plus Phase 3 cross-cutting findings. Branch: `audit/haiku-combined` (local only, not pushed).

## Result at a glance

- Phase 1 survey: 1,454 unique findings from 58 shards. Coverage: every shard read to 100% of its file ranges (see coverage table).
- Phase 3 cross-cutting: 40 new findings across 10 groups.
- Phase 4 verification: 1,494 items, all verified. 1,418 confirmed, 68 confirmed with correction, 5 false positive, 3 unclear. Precision of usable verdicts: 1,486 of 1,494 (99.5%).
- Phase 5 mechanical fixes: 8 Haiku worktree branches, one per crate batch. 616 items in scope; 0 touched code outside comments, docs, TODOs, CI or private dead-code removal. 43 items skipped with reasons (listed below).
- Final gate on the combined branch (with the verification-only overlay below): `cargo test --workspace` 2,902 passed, 0 failed. `cargo clippy --all-targets --workspace` 0 errors after allowing three lints that predate the audit.

## Caveats the reader must know

1. **The combined branch does not compile on its own.** `main` already fails: six call sites in `crates/smelt-codegen-rust/src/emitter/coercion.rs` (lines 474, 475, 1069, 1070, 1583, 2064) omit the `&RenderScope` argument to `list_items_render_as_unknown`. Verification used a six-line overlay (pass `&self.render_scope()` at each site) applied in a throwaway worktree and never committed. The fix needs a decision before any branch can build.
2. **Three lints predate the audit and fail under the repo's `pedantic = deny` config.** Verification allowed them on the command line only, and they are NOT fixed here: `clippy::struct_excessive_bools` on `EmitContext` (`crates/smelt-codegen-rust/src/emitter/mod.rs:163`); `clippy::needless_raw_string_hashes` (`crates/smelt-frontend-ts/src/tests/part04_tests.rs`, `crates/smelt-codegen-rust/src/tests/part_7_tests.rs`); `clippy::doc_markdown` (`crates/smelt-transpiler/tests/hir_cli_typescript_tests.rs:617`, `RegExp`). Each is identical on `main`.
3. **Verifier quality is uneven.** The `reason`/`checked` fields for most confirmed items are generic text, not per-finding notes. Batch 08 was spot-checked (five items), not fully re-read. Batch 14 did not re-check three claims (F1042, F1046, F1096, F1097). Treat the precision figures as an estimate of claim accuracy, not a proof.
4. **Phase 5 fixes were not compiled by their own agents** (agents had no cargo). All verification happened afterwards on the combined branch. Each branch's diff was reviewed for code-level changes, and the three that touched code (frontend-py import removal, transpiler/misc clap doc, codegen private dead-code removal) were checked by compile and test.
5. **User-visible text changed.** Doc comments in `crates/smelt-transpiler/src/cli_parser.rs` are clap `--help` text (`smelt check --help`, `new --help`, `clean --help`).
