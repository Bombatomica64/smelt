how to use it

Install CRATES.IO SOON

cargo install smelt

# until then, from source:
git clone \
  https://github.com/Bombatomica64/smelt
cargo install --path smelt/crates/smelt-cli

One binary: smelt. Rust 1.85+ with edition 2024.

Describe the project

# Smelt.toml
[project]
name = "my-lib"

[sources]
roots   = ["src"]
entries = ["src/index.ts"]

[output]
target     = "./dist-smelt"
crate-name = "my_lib"

Point it at your strictly-typed sources; tests are picked up as test globs.

Smelt & test

smelt --manifest-path Smelt.toml build
cargo test --manifest-path \
  dist-smelt/Cargo.toml

Your Vitest / pytest suites come out the other side as native Rust tests.
